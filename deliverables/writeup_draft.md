# Классификация степени зрелости фруктов по изображениям

## 1. Задача и существующие решения

Проект решает задачу автоматического определения степени зрелости авокадо по одной фотографии: сорттировочные линии и обычные покупатели получают метку стадии без разрезания плода. На вход — цветное фото одного фрукта (JPEG, RGB), на выход — метка стадии зрелости: **unripe** (незрелое, зелёное), **ripe** (спелое, тёмно-зелёное) или **overripe** (перезревшее, почти чёрное) с вероятностями.

Аналоги и подходы:
- **Ручная сортировка / инструментальные методы** (этилен-датчики, спектроскопия): точны, но требуют контакта с плодом или дорогого оборудования; по фотографии из приложения не работают.
- **Классические CV-методы** (пороги RGB/HSV, текстурные признаки + SVM): быстро и объяснимо, но чувствительны к фону/освещению и падают на похожих стадиях (тёмно-зелёное незрелое vs спелое).
- **Deep learning / transfer learning CNN** (наш выбор): свёрточная сеть, предобученная на ImageNet, дообучается на классах авокадо; публичные ноутбуки на Fruits-360 показывают accuracy 95–100% на распознавание видов фруктов.

Выбран **transfer learning на MobileNetV2** с 3-классовой головой: лёгкая (3.4M параметров), быстро обучается на бесплатном GPU Kaggle, стандартный индустриальный подход для малых датасетов.

## 2. Данные и подготовка

- **Источник:** Fruits-360 (https://www.kaggle.com/datasets/moltean/fruits, версия 2026.11, ветка fruits-360_100x100) — студийные фото на белом фоне.
- **Структура:** 5 классов авокадо → 3 стадии: `Avocado Green 1` → unripe (933), `Avocado 1`/`Avocado 2` → ripe (1227), `Avocado Black 1`/`Avocado Black 2` → overripe (1917). Всего 4077 файлов JPEG 100×100 RGB.
- **Проверки качества (задание 02):** все файлы читаются (0 ошибок), размеры/режим/диапазон корректны, метки определяются класс-папкой; найдена 1 пара точных дубликатов по sha256 — копия удалена (4076 после очистки).
- **Разделение:** официальный Test (1017) сохранён как итоговый тест (задание 06); внутри Training — train 2600 / validation 459 (стратифицированно, RANDOM_STATE=42). Пересечения ID/путей/хешей между всеми частями проверены — их нет.
- **Дисбаланс классов 23%/30%/47%** → основная метрика macro-F1, accuracy приводится справочно.
- **Предобработка:** ресайз 100×100 → 224×224 (вход MobileNetV2) и нормализация 1/255 — реализованы слоями модели (единый конвейер для всех частей); аугментации только на train и только геометрические (flip, rotation 0.1, zoom 0.1) — цвет не меняем, поскольку именно цвет кодирует стадию.
- Исследование признаков (задание 02, п. 4.3): классы упорядочены по яркости (unripe светлее всех, overripe темнее всех), распределения соседних стадий частично перекрываются — ожидаем ошибки прежде всего на паре ripe↔overripe.

## 3. Модель и эксперименты

## 5. Результаты и выводы

Итоговая проверка на отложенном тесте (1017 изображений) — задание 06. Текущий статус по validation: accuracy 0.996, macro-F1 0.996, 2 ошибки (обе — тёмно-зелёное незрелое авокадо принято за перезревшее). Обучение — GPU Tesla T4 на Kaggle (~16 c/эпоха). Ограничения: студийный белый фон датасета — на фото из магазина с другим фоном качество может упасть; соседние стадии зрелости частично неразличимы даже для человека.
